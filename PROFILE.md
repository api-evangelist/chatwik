# Chatwik

Modern omnichannel customer communication platform (operated by ZeroFlux Technologies) combining live chat, social media messaging, a multi-agent shared inbox, CRM workspace, and the WikAI autonomous AI support assistant. Currently exposes an llms.txt agent-native discovery file and an embeddable JavaScript Widget SDK; a REST/webhook developer API is advertised but not yet documented (targeted ~August 2026).
